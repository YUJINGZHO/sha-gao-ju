# Gameplay Frame Visual Demos（历史资料）

正式视觉方向以根目录 [`../../DESIGN.md`](../../DESIGN.md) 为准。本目录的 frame demo 仅用于追溯参考镜框构图。

当前优先参考 Demo：[`reference-mirror.html`](./reference-mirror.html)。它以最新参考图为最高视觉依据，使用同一套高保真场景的桌面与移动构图。

目标不是把 CSS 组合成一张网页卡片，而是让镜框、房间、糕点、光线和 HUD 看起来属于同一个完整的游戏画面。

打开 `index.html` 查看早期 A / B / C 框型对比；打开 `reference-mirror.html` 查看目前更接近参考图的完整方向。

- **A · Ornate Mirror**：雕花奶油镜框，粉色缎带与金色细边。
- **B · Patisserie Display Window**：更轻、更清爽的玻璃展示窗。
- **C · Cream Cake Frame**：奶油裱花边框、小蝴蝶结与甜品细节。

三者共用：

- 同一张外部 Coquette Patisserie 环境图。
- 同一张内部软 3D 糕点舞台图：桂花糕、草莓奶油糕、绿豆糕、糕盘 hazard。
- 同一组 SCORE / TIME / LIVES、slash trail、combo 和操作提示。

本目录是视觉探索产物，不接入正式项目。确认方向后，再实现正式 Gameplay Frame。
