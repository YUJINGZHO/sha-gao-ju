# Ribbon Window Patisserie（历史探索提示词）

正式项目规范请以 [`../../DESIGN.md`](../../DESIGN.md) 为唯一来源；本文件不再作为生产资产生成指令。

## Art direction

奶油白与 ballet pink 的精品甜品店。窗边自然光、雕花奶油色牌匾、金色细边、大型缎带蝴蝶结、蛋糕架、茶杯、瓷盘、草莓奶油蛋糕，以及少量桂花、桃花和月兔细节。

## Generation constraints

- 输出两种比例：竖版 4:5、横版 16:9。
- 使用软 3D miniature illustration，强调前景 / 中景 / 背景层次与柔和景深。
- 保留平静的中央牌匾或桌面区域，供 HTML 叠加 Home、Playing / HUD、Game Over 文案。
- 不生成可读文字、Logo、水印、网页 UI，不复制参考图布局。
- UI 文案后置使用：可爱杀糕局、KE AI SHA GAO JU、开糕、BEST TODAY、今日糕单、甜点台收工、再来一局、返回首页。
